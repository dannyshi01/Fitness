# 🏋️ 健身菜單 & 動作庫

一個給自己用的健身小工具:**收錄動作**(建立個人動作庫)+ **安排訓練菜單**(依訓練日排課表),解決「到健身房不知道練什麼、看到好動作不知道往哪放」的問題。

單一 HTML 檔、純前端、免安裝、免登入、免網路。資料存在你自己的瀏覽器裡。

## 功能
- **📚 動作庫**:收錄每個動作,可存
  - 名稱、部位分類(可多選)、器材
  - 來源(IG / YouTube / 實體課 / 教練…)與**來源連結**(之後點一下就回去看原影片)
  - 教練提示 / 筆記
  - **動作示範圖片**(自動壓縮縮圖,不佔空間)
  - 支援搜尋 + 部位篩選,快速找到動作
  - 右下角 ＋ 只要填名稱就能存,看到好動作可以先丟進來、之後再補分類
- **📋 菜單**:依訓練日安排(推日 / 拉日 / 腿日…),從動作庫勾選動作、填組數 × 次數,到健身房照著做
- **匯出 / 匯入**:一鍵備份成 JSON,可在裝置之間手動搬移

## 使用方式
1. 直接用瀏覽器打開 `index.html` 即可。
2. **加到手機主畫面像 App**:
   - iPhone(Safari):分享 → 加入主畫面
   - Android(Chrome):右上選單 → 加到主畫面

## 資料儲存與備份
- 所有資料存在瀏覽器的 `localStorage`,**只存在你這台裝置**,不會上傳到任何地方。
- 清除瀏覽器資料 / 換裝置會遺失,所以請善用右上角「匯出」定期備份成 JSON;換裝置時用「匯入」還原。

## 技術
- 原生 HTML + CSS + JavaScript,無框架、無 build、無相依套件。
- 圖片以 canvas 壓縮成最長邊 720px 的 JPEG 後存成 base64。

## 之後可延伸
訓練紀錄(每次實際重量/次數)、依部位自動推薦動作、雲端同步、影片內嵌預覽。
